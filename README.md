# Task-mangment-Dashbord

This project focuses on a task management dashboard where users can log into the system using JWT authentication. It allows users to update, create, delete, and view tasks. The dashboard displays the total, pending, and completed tasks. The task fields include title, description, priority, status, and due date. The dashboard's statistics show the total, pending, and completed tasks. Additionally, it features search and filter options for tasks, ensuring a responsive and clean user interface. The project integrates a MongoDB database and utilizes Tailwind CSS for a responsive UI, along with a RESTful API built with Express.

Installation
Clone the repository.
Install dependencies.
Set up environment variables.
Run the application locally.
